# Quarterly 가이드 — 분기 성과평가

## 절차

1. **분기 확정** — 기본: 직전 분기. `2026-Q1`처럼 지정 가능.
2. **Monthly 백필** — 해당 분기 Monthly 3개 존재 확인 → 누락분은 [monthly.md](monthly.md) 절차로 **먼저 생성**.
3. **okr-master.md 로드** — 상위과제 제목·가중치·KR 문안·정량 지표 항목 (이 파일이 원본이다. 문안을 임의로 바꾸지 않는다).
4. **작성** — Monthly 3개(+세부 확인이 필요할 때만 Weekly 원본 참조)로 아래 골격 작성.
5. **자체 점검** — 4개 상위과제 전부 존재 / KR 매핑 누락 없음 / Part 2 서식이 weekly.md §6 규격 / 시크릿 값 0건.

## 골격 (실물 2026-Q1과 동일 구조)

프론트매터는 Weekly와 동일(weekly.md §4). 파일명: `Quarterly/YYYY-Qn_quarterly-okr.md`.

## 주의

- okr-master의 `## 정량 지표 추적` 표는 **갱신하지 않는다**(기존 노트 수정 금지). 대신 분기 성과 요약에 동일 항목의 카운트를 제시해 사용자가 옮겨 적을 수 있게 한다.
- 분기 초 Weekly가 구형 형식·구형 태그 체계(2026-03 이전)를 포함할 수 있다 — Weekly Part 1에 적힌 태그를 그대로 믿지 말고 okr-master의 현행 태그 체계로 정규화한다.
